# School Money Management System

## Overview
This is a Java console-based application developed using Object Oriented Programming concepts.

The system manages:
- Student fee payments
- Teacher salary payments
- School balance management

---

## Technologies Used
- Java
- OOP Concepts
- ArrayList
- Scanner Class

---

## Features
- Pay student fees
- Pay teacher salaries
- View school balance
- Menu-driven application

---

## OOP Concepts Used
- Encapsulation
- Aggregation
- Classes and Objects
- Constructors
- Static Variables and Methods
